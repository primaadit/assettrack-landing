Fitur Unggulan

Semua yang Dibutuhkan
Tim IT & Finance

🔒
Atomic Lock Peminjaman
Sistem PostgreSQL-level lock memastikan tidak ada double booking. Satu aset, satu peminjam — tanpa race condition.
📷
Dokumentasi Foto Wajib
Foto kondisi sebelum dipinjam dan sesudah dikembalikan. Bukti fisik tersimpan, konflik kondisi aset teratasi.
🔄
Real-Time Sync
Status aset berubah → semua user langsung ter-update via Supabase Realtime. Tidak perlu refresh manual.
🤖
AI Condition Summary
Sistem otomatis generate laporan kondisi aset before/after berdasarkan data yang diinput. Dokumentasi tanpa effort.
👥
RBAC Divisi
Manager hanya lihat data divisinya. Admin lihat semua. Director view executive. Role-based access control yang tepat.
📊
Laporan Depresiasi
Hitung nilai depresiasi aset otomatis per kategori. Export ke Excel untuk keperluan finance dan audit.
📱
QR Code per Aset
Generate & cetak QR unik untuk setiap aset. Scan = langsung lihat detail, status, dan history peminjaman.
📋
Audit Log Lengkap
Setiap aksi tercatat: siapa approve, kapan dipinjam, kondisi saat return. Trail tidak bisa dihapus.
🚗
Modul Kendaraan
Catat KM awal/akhir, kondisi bensin, foto odometer. Lengkap untuk fleet management kendaraan operasional.
